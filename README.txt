Created by Ruval Gouws

CONTENTS
- index.html: the complete responsive webpage
- resources/: posters, learner brief, instructions, starter files and teacher guide

HOW TO USE
1. Keep index.html and the resources folder together.
2. Upload the complete folder contents to a web host that supports static HTML, or use the files as the basis for a site in your chosen website builder.
3. Open index.html in a browser to preview locally.
4. Resource download links are relative paths, so do not rename or move the files out of the resources folder unless you also update the links.
